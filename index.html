Esperando al juego

Abre Rocket League con la Stats API activada. El panel se conecta solo a y lo reintenta cada 2 segundos.

Para activarla, edita TAGame\Config\TAStatsAPI.ini (o DefaultStatsAPI.ini) en la carpeta de instalación del juego, con el juego cerrado:

[TAGame.MatchStatsExporter_TA]
PacketSendRate=30
WebPort=49124
Port=0

Port=0 cierra el socket TCP (49123) que el juego abre además del WebSocket; el panel no lo usa.

Pulsa “Modo demo” para ver el panel con datos simulados.
